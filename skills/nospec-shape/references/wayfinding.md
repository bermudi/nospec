# Wayfinding across sessions

Read this when shaping itself spans fresh context windows and the route to the outcome is still unclear. If the outcome and route fit one session, shape it directly or use `nospec-carve`.

Name the target outcome first; it fixes scope. Keep a disposable map in the cycle's work-spec area (for example, `.loop/<name>/specs/`) with the outcome, constraints, accepted decisions, precise open questions, dependencies, in-scope fog, and explicit out-of-scope boundaries. Link detailed evidence from the map instead of copying it into the index.

A **decision question** resolves one decision; it is not a `QUEUE.md` work unit. Only make a question live when it can be stated precisely. Open, unblocked questions form the frontier. A fresh session usually takes one question; independent AFK research that is safe to run in parallel is an exception. Rechart after each answer: it may expose, merge, invalidate, or graduate questions.

Choose evidence deliberately: owner conversation for intent or consequential trade-offs; research for external facts; a disposable prototype or scouting experiment for concrete feedback; a prerequisite task only when it unlocks evidence. Never answer for the decision owner.

Stop when the remaining route is bounded outcomes with no unresolved consequential questions. Extract accepted rulings through `nospec-curator`, then read `queue-format.md` only for an execution handoff. Delete the map and questions with the work; they are coordination state, not contracts or source of truth.
